기능

읽기 어려운 이유를 하나씩 풀었어요

같은 PDF를 누구나 자기 방식으로 볼 수 있도록 필요한 변환을 한곳에 모았습니다.

  • 읽기 구조화

    글자를 뽑고 읽는 순서를 바로잡습니다. 사라진 띄어쓰기를 복원하고, 색으로만 강조된 말은 굵은 밑줄로 바꿔요.

  • 그림·도식 설명

    이미지 속 이름표까지 읽고 그림이 무엇을 보여 주는지 글로 설명합니다. AI가 쓴 부분에는 표시가 붙어요.

  • 보기 편하게

    글씨 크기, 줄 간격, 글꼴, 고대비 테마를 내 눈에 맞춥니다. 설정은 기억해 둬요.

  • 색각 이상 지원

    색이 칠해진 그림은 구분이 잘 되도록 색을 보정하고, 같은 색에 같은 무늬를 얹어 줍니다.

  • 음성 읽기

    문단 단위로 읽고 속도를 조절할 수 있어요. 코드는 괄호와 들여쓰기까지 말해 줍니다.

  • 한글 점자

    한국 점자 규정에 맞춰 변환하고, 점자 프린터용 파일로 내려받을 수 있어요.
